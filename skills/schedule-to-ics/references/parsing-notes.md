# 课表与作息时间表解析细则

第 1 步和第 3 步遇到拿不准的写法时读这里。

## 周数写法

| 写法 | 含义 |
| --- | --- |
| `1-16周` | 第 1 到 16 周每周都上 |
| `1-16周(单)` / `1-16周单周` / `1,3,5…15周` | 只上单周 |
| `1-16周(双)` / `2-16周双周` | 只上双周 |
| `1-8,10-16周` | 两段周数，跳过第 9 周 |
| `1-16周(单),17周` | 混合写法，需要拆成两行记录 |

一门课在同一星期、同一节次但周数分段（同一分段内教室也可能不同）时，拆成多行。判不准周数含义时按原文字面列出并问用户，不要自己推算。

## 节次写法

- 网格课表中一行一个节次（第 1 节、第 2 节……），上午、下午、晚上通常连续编号。
- 同一门课的单元格跨几行 → 就是连堂，节次写成 `1-2`、`3-4`。
- 有的学校按"大节"编号（第 1 大节 = 第 1-2 小节），此时节次要和作息时间表的编号方式保持一致，不确定就问用户。
- 单元格里出现两门不同课程 → 说明时间冲突，两行都记，并在表格下方提示冲突。

## 教室与教学楼

- 教室号常写成 `A101`、`教1-101`、`1号楼101`、`A-101`。
- 教学楼可能是教室号的前缀，例如"教1-A101"。拆分时教学楼填 `教1`，教室编号填 `A101`；楼层或座位号之类的信息不要塞进教室编号。
- 原图没写教学楼、只有教室号 → 教学楼留空，并提示用户确认。
- 体育课、实验课、机房常写场馆名（如"体育馆""物理实验中心"）而不是教室号，照原样填进教室编号。

## 作息时间表

- 常见形式：`第 1 节 08:00-08:45`、表格两列（节次 / 时间）、或一张带上午下午分段的图。
- 常见坑：一节课 45 分钟但节次间隔更大（含课间休息）；上午下午晚上用不同编号体系；有的只给"大节"的时间（第 1-2 节 08:00-09:35）。
- 只需要每节的开始和结束时间。作息表和课表的节次编号必须对得上，对不上就停下来问用户，不要拼接。

## 什么时候必须问用户

- 图片模糊、字段被截断、字看不清。
- 周数、节次、教室有歧义，或两种解释都说得通。
- 同一时间段出现多门课。
- 作息时间表缺了课表中用到的节次。
