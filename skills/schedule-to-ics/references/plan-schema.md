# plan JSON 字段说明

`generate_ics.py` 的输入。所有字段名都是英文小写，值可以用中文。写文件时用 **UTF-8 无 BOM**。

```json
{
  "semester": {
    "current_week": 3,
    "total_weeks": 16,
    "week1_monday": "2026-08-24",
    "parity": "单"
  },
  "from_date": "2026-09-11",
  "reminder_minutes": 15,
  "timezone": "Asia/Shanghai",
  "tz_offset": "+08:00",
  "periods": {
    "1": ["08:00", "08:45"],
    "2": ["08:50", "09:35"]
  },
  "courses": [
    {
      "course": "高等数学",
      "building": "教1",
      "room": "A101",
      "weekday": 1,
      "periods": [1, 2],
      "weeks": "1-16"
    }
  ]
}
```

## 顶层字段

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `semester.current_week` | 是 | 当前第几周，用户在第 2 步告知 |
| `semester.total_weeks` | 是 | 一学期共几周，用来裁剪周数范围 |
| `semester.week1_monday` | 否 | 第 1 周周一（`YYYY-MM-DD`）。省略时按「今天 − (当前周 − 1) × 7 天」反推 |
| `semester.parity` | 否 | `单` 或 `双`；填了会校验当前周奇偶是否与之一致，不一致直接报错，避免整学期错位 |
| `from_date` | 否 | 从哪天开始排，默认今天；已过去的课不会出现在日历里 |
| `reminder_minutes` | 否 | 提前提醒分钟数；省略或为 `null` 就是不加提醒 |
| `timezone` | 否 | 默认 `Asia/Shanghai` |
| `tz_offset` | 否 | 默认 `+08:00`，写进 VTIMEZONE |
| `periods` | 是 | 节次 → 起止时间，见下 |
| `courses` | 是 | 课程列表，见下 |

## periods

键是节次号，值是 `["开始", "结束"]`，24 小时制。也接受 `"08:00-08:45"` 字符串和 `{"start": "...", "end": "..."}` 对象。

```json
"periods": {
  "1": ["08:00", "08:45"],
  "2": ["08:50", "09:35"],
  "3": ["10:00", "10:45"],
  "4": ["10:50", "11:35"]
}
```

注意：

- 时间可以写 `8:00`，脚本会补零。
- 结束时间必须晚于开始时间，否则报错。
- 课表里用到的每个节次都必须在 `periods` 里出现，缺一个就会停下来报错（不会猜时间）。
- 如果学校按「大节」编号，`periods` 的编号方式要和课表一致。

## courses 条目

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `course` | 是 | 科目名，如 `高等数学` |
| `weekday` | 是 | 1=周一 … 7=周日（不是 0 起，也不是「周一」字符串） |
| `periods` | 是 | 节次数组，如 `[1, 2]`；连堂如实写两个节次，脚本会自动合并成一个事件 |
| `weeks` | 是 | 上课周数，写法见下 |
| `room` | 否 | 教室编号，如 `A101` |
| `building` | 否 | 教学楼，如 `教1` |

`week` 相关字段都没填的课会被跳过，不会静默产生错误事件。

## weeks 支持写法

| 写法 | 含义 |
| --- | --- |
| `1-16` | 第 1 到 16 周每周都上 |
| `1-16(单)` / `1-16单周` / `单周` | 只上单周 |
| `1-16(双)` / `2-16双周` / `双周` | 只上双周 |
| `1-8,10-16` | 两段，跳过第 9 周 |
| `3-15(双)` | 3 到 15 周里的双周 |

`周`、`第` 这些字可以带也可以不带；全角括号、`～`、`至` 都会自动归一化。

超出 `1..total_weeks` 的周数会被忽略，并在 stderr 打一条警告——出现警告通常说明总周数填错了，值得回头核一遍。

## 合并与排期规则（由脚本负责，不要手工预处理）

- 同一天、同一门课、同一教室、连续节次 → 合并成一个事件（第 1-2 节 08:00–09:35）。
- 不连续的节次不会硬合并（第 1 节和第 3 节是两条记录）。
- 周数连续用 `RRULE:FREQ=WEEKLY;INTERVAL=1;COUNT=n`；单双周用 `INTERVAL=2`；不连续周数拆成多个事件。
- 只排 `from_date` 之后的日期，已经上过的课不会重复写进日历。

## 常见错误

| 错误 | 症状 | 修正 |
| --- | --- | --- |
| `weekday` 写 0-6 | 报错「weekday 必须是 1-7」 | 周日=7 |
| `periods` 用字符串 `"1-2"` | 报错 | 写成数组 `[1, 2]` |
| 周数写成 `1~16周` | 能识别（会归一化） | 无需改，但建议写成 `1-16` |
| 楼号塞进 `room`，如 `教1-A101` | 标题变长但不报错 | `building` 填 `教1`，`room` 填 `A101` |
| 作息表缺第 9、10 节 | 报错并指出缺哪节 | 补全 `periods` 后再生成 |
| plan.json 存成 UTF-16 / 带 BOM | 解析失败或报编码错 | 另存为 UTF-8（脚本已容忍 BOM） |
